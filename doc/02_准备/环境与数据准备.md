# 环境与数据准备

## 1. 固定实验环境

所有实验统一在以下 conda 环境中运行：

- `D:\Anaconda_envs\PulseWeave`

约束：

1. 不跳出该环境运行
2. 模型缓存尽量放在项目目录内
3. 不额外下载新的数据集

## 2. 主要依赖

当前实验已使用的核心依赖包括：

- `torch`
- `torchvision`
- `numpy`
- `scipy`
- `opencv-python`
- `matplotlib`
- `pandas`
- `Pillow`
- `h5py`
- `tqdm`
- `tensorboardX`

## 3. 数据集准备

### 3.1 NYUv2

当前使用目录：

- `data/nyuv2/official_splits/train`
- `data/nyuv2/official_splits/test`

当前使用文件列表：

- `data/nyuv2/bts_inputs/nyu_train_official.txt`
- `data/nyuv2/bts_inputs/nyu_test_official.txt`

### 3.2 DIODE

当前使用目录：

- `data/diode`

当前使用划分文件：

- `data/diode/splits/train.csv`
- `data/diode/splits/val.csv`
- `data/diode/splits/test.csv`

当前规模：

- train：`616`
- val：`76`
- test：`79`

## 4. 代码目录准备

- `refs/`：开源仓库源码
- `src/`：本地启动脚本与冒烟测试脚本
- `configs/`：BTS 参数文件
- `outputs/logs/`：训练日志与 checkpoint
- `outputs/results/`：结果、评估输出、可视化
- `doc/`：说明文档、修改记录、运行记录
