# 开源代码来源

本文档用于明确本项目使用的开源仓库来源，便于实验报告、答辩和后续复现。

## 1. BTS

- 仓库名称：`BTS`
- 论文名称：`From Big to Small: Multi-Scale Local Planar Guidance for Monocular Depth Estimation`
- GitHub：`https://github.com/cleinc/bts`
- 本地路径：`refs/bts`
- 本项目用途：
  - NYUv2 baseline
  - DIODE baseline

## 2. GuidedDecoding

- 仓库名称：`GuidedDecoding`
- GitHub：`https://github.com/mic-rud/GuidedDecoding`
- 本地路径：`refs/GuidedDecoding`
- 本项目用途：
  - NYUv2 baseline
  - DIODE baseline
  - 作为主要对比实验仓库之一

## 3. ZoeDepth

- 仓库名称：`ZoeDepth`
- 论文名称：`ZoeDepth: Zero-shot Transfer by Combining Relative and Metric Depth`
- GitHub：`https://github.com/isl-org/ZoeDepth`
- 本地路径：`refs/ZoeDepth`
- 本项目用途：
  - 进行可行性尝试与兼容性验证
  - 保留实验记录
  - 当前不作为主对比基线

## 4. 使用原则说明

1. 开源仓库源码统一保存在 `refs/`
2. 本地所有适配、补丁、脚本和运行记录均在项目内保留
3. 不隐藏开源来源，后续实验报告可直接据此说明使用了哪些公开代码
4. 具体改动见：
   - [代码适配与修改记录](D:\机器视觉设计与实践\doc\03_实现\代码适配与修改记录.md)
   - [对比仓库适配说明](D:\机器视觉设计与实践\doc\03_实现\对比仓库适配说明.md)
