- 文件：`refs/GuidedDecoding/training.py`
- 代码位置：
  - `refs/GuidedDecoding/training.py:77-92`
  - `refs/GuidedDecoding/training.py:149-151`
  - `refs/GuidedDecoding/training.py:175-198`
- 修改：
  - 训练阶段每轮只覆盖保存 `latest.pth`
  - 验证最优时保存 `best.pth`
  - 训练结束保存 `final.pth`
  - `save_model()` 导出 `best_model.pth`
- 原因：
  - 避免每轮都生成一个 checkpoint，便于管理与复现

### 2.6 修复指标计算中的无效值问题

- 文件：`refs/GuidedDecoding/metrics.py`
- 代码位置：`refs/GuidedDecoding/metrics.py:41-69`
- 修改：
  - 对 `output`、`target` 加入有效像素筛选：
    - `torch.isfinite(...)`
    - `output > 0`
    - `target > 0`
- 原因：
  - 避免 `REL / Lg10 / delta / rmse_log` 在零深度或非法深度下变成 `nan/inf`

### 3.6 修复 DIODE 深度与掩码维度不一致

- 文件：`refs/GuidedDecoding/data/diode_local.py`
- 代码位置：`refs/GuidedDecoding/data/diode_local.py:37-45`
- 本次新增修改：
  - 若 `depth.shape == (H, W, 1)`，压缩为 `(H, W)`
  - 若 `mask.shape == (H, W, 1)`，压缩为 `(H, W)`
  - 对深度执行 `np.nan_to_num(...)`
  - 再使用 `mask` 过滤无效像素
- 原因：
  - 原始 DIODE 的 `depth.npy` 与 `mask.npy` 在不同样本上可能出现二维/三维差异
  - 直接 `np.where(mask, depth, 0.0)` 会出现广播错误

## 7. 创新版 BTS：Edge-Guided BTS 第一版实现

### 7.1 模型结构改动

- 文件：`refs/bts/pytorch/bts.py`
- 代码位置：
  - `refs/bts/pytorch/bts.py:156-212`
  - `refs/bts/pytorch/bts.py:276-295`

### 7.2 改动内容

1. 增加 `use_edge_guidance` 开关
2. 在解码器末端增加边缘分支：
   - `edge_feature`
   - `edge_predict`
3. 使用边缘概率图调制 `upconv1`
4. 在最终深度预测前将边缘图拼接进 `concat1`
5. 在启用创新版时，模型额外输出：
   - `edge_logits`

### 7.3 改动原因

原始 `BTS` 更强调局部平面几何恢复，边界区域容易偏平滑。新增边缘分支后，可以在最终细化阶段显式增强边界响应。

### 7.4 训练逻辑改动

- 文件：`refs/bts/pytorch/bts_main.py`
- 代码位置：
  - `refs/bts/pytorch/bts_main.py:114-116`
  - `refs/bts/pytorch/bts_main.py:178-194`
  - `refs/bts/pytorch/bts_main.py:336-340`
  - `refs/bts/pytorch/bts_main.py:495-550`
  - `refs/bts/pytorch/bts_main.py:587-602`

### 7.5 改动内容

1. 新增参数：
   - `--use_edge_guidance`
   - `--edge_loss_weight`
2. 新增 `compute_depth_edge_target(...)`
   - 从 GT 深度构造边缘监督
3. 训练时新增边缘损失：
   - `edge_loss = BCEWithLogitsLoss(edge_logits, edge_target)`
4. 总损失改为：
   - `silog_loss + edge_loss_weight * edge_loss`
5. TensorBoard 新增：
   - `edge_loss`
   - `edge_pred`
