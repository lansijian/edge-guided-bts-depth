# 创新方案：Edge-Guided BTS

## 1. 创新方案名称

### 中文名称

基于边缘引导细化的 BTS 单目深度估计改进方法

### 英文名称

Edge-Guided Refinement BTS for Monocular Depth Estimation

## 2. 选择 BTS 作为创新底座的原因

当前已经跑通的主 baseline 有：

1. `BTS`
2. `GuidedDecoding`

最终选择 `BTS` 作为创新底座，原因如下：

1. `BTS` 在当前环境下训练和评估最稳定
2. `BTS` 的 baseline 结果更可信、链路更完整
3. `BTS` 的核心是局部平面引导，擅长恢复整体几何结构
4. `BTS` 的短板主要在边缘与深度突变区域，适合叠加边缘细化模块

## 3. BTS 核心算法概括

`BTS` 的核心思路不是直接逐像素回归深度，而是：

1. 使用编码器提取多尺度特征
2. 使用解码器逐级恢复空间分辨率
3. 在多个尺度上预测局部平面参数
4. 使用 `Local Planar Guidance (LPG)` 恢复深度

因此，`BTS` 的优点是：

- 全局结构稳定
- 对室内平面结构友好
- 深度图整体较平滑

不足主要在：

- 边界处可能过于平滑
- 深度跳变位置不够锐利
- 小目标边缘细节不够强

## 4. 创新核心思想

在原始 `BTS` 的基础上，引入一个轻量边缘引导细化模块。

目标是：

1. 从 RGB 图像中提取边缘信息
2. 将边缘信息用于调制解码阶段的深度特征
3. 同时通过边缘监督约束模型学习更清晰的深度边界

## 5. 方案结构

创新方案由三部分组成：

### 5.1 边缘分支

- 输入：原始 RGB 图像
- 输出：边缘特征图 / 边缘概率图

作用：

- 提供边界线索
- 指导后续深度细化

### 5.2 边缘引导融合

- 将边缘特征与 BTS 解码器末端特征融合
- 生成更加关注边界区域的深度细化特征

作用：

- 保留 BTS 的几何结构优势
- 增强边界区域表达能力

### 5.3 边缘损失

- 从 GT 深度图构造边缘监督
- 约束预测深度在边缘区域与 GT 更一致

作用：

- 避免只靠结构改动而无明确边缘监督
- 提升训练稳定性

## 6. 预期改进点

相较于原始 `BTS`，预期提升包括：

1. 物体边界更清晰
2. 深度突变区域更准确
3. 可视化结果更自然
4. `abs_rel`、`rms`、`d1` 等指标有提升空间

## 7. 实验设计

### 7.1 对比实验

1. `BTS`
2. `GuidedDecoding`
3. `Edge-Guided BTS`

### 7.2 消融实验

1. `BTS`
2. `BTS + edge loss`
3. `BTS + edge branch`
4. `BTS + edge branch + edge loss`

### 7.3 可视化实验

建议输出：

1. 原图
2. GT 深度
3. BTS 预测深度
4. 改进方法预测深度
5. 误差图
6. 边缘图

## 8. 实现原则

为了保证当前设备能跑通，创新实现遵循以下原则：

1. 模块轻量化
2. 不更换主干编码器
3. 尽量复用原始 BTS 训练流程
4. 先实现最小可训练版本，再逐步加实验项

## 9. 最终实验进展

目前已经完成：

1. `NYUv2` 三组完整创新实验
   - `Edge-Guided BTS (edge_loss_weight = 0.10)`
   - `Edge-Guided BTS (edge_loss_weight = 0.02)`
   - `Edge-Guided BTS (edge_loss_weight = 0.05)`
2. `DIODE` 两组完整创新实验
   - `Edge-Guided BTS (edge_loss_weight = 0.05)`
   - `Edge-Guided BTS (edge_loss_weight = 0.02)`
3. `NYUv2` 与 `DIODE` 消融实验

最终结论：

1. `NYUv2` 最优配置为 `0.05`
2. `DIODE` 最优配置为 `0.02`
3. `edge loss` 是主要收益来源
4. 完整模型在合适权重下进一步提升表现
