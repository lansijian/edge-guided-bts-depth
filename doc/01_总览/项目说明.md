# 项目说明

## 1. 课题

单目深度估计课程设计。

## 2. 数据集

- `NYUv2`
- `DIODE`

## 3. 实验路线

本项目按以下顺序完成：

1. 固定实验环境
2. 适配本地数据集
3. 复现开源 baseline
4. 选择最稳的 baseline 作为创新底座
5. 实现创新方法
6. 完成对比实验、消融实验与可视化分析

1. `BTS`

   - DIODE
2. `GuidedDecoding`
   - NYUv2
   - DIODE

### 4.2 非主线尝试

- `ZoeDepth`
  - 已做兼容性尝试与评估链路验证
  - 当前不作为主要创新底座

## 5. 创新主线

最终确定的创新方案为：

**方案 B：基于边缘引导细化模块的 BTS 改进方法**

暂定名称：

- 中文：`基于边缘引导细化的 BTS 单目深度估计改进方法`
- 英文：`Edge-Guided Refinement BTS for Monocular Depth Estimation`

## 6. 最终结果

### 6.1 最优创新模型

- `NYUv2`：
  - `bts_nyu_edgeguided_w005`
- `DIODE`：
  - `bts_diode_edgeguided_w002`

### 6.2 消融结论

1. `NYUv2` 上的主要收益先来自 `edge loss`
2. `NYUv2` 上分支与监督联合后，`w=0.05` 最优
3. `DIODE` 上 `edge branch only` 会明显退化
4. `DIODE` 上只有较小权重 `w=0.02` 的完整方案有效

### 6.3 对比方法状态

- `BTS` baseline：已完成
- `GuidedDecoding` baseline：已完成
- `ZoeDepth`：保留尝试记录，不作为主对比基线

## 7. 目标

基于 `BTS` baseline，加入轻量边缘分支与边缘损失，在保证可训练、可复现的前提下，提升：

- 边界区域深度质量
- 整体误差指标
- 可视化效果
