## 3. 创新方案选择结论

最终选择：

- **主创新底座：`BTS`**
- **对比方法：`GuidedDecoding`**

原因：

1. `BTS` 在当前环境下更稳
2. `BTS` 的训练与评估链路已经完整跑通
3. `BTS` 的局部平面结构适合继续叠加边界细化模块
4. `GuidedDecoding` 更适合作为对比实验，而不是主创新底座

## 4. 创新方向

最终确定为：

**方案 B：BTS + 轻量边缘分支 + 边缘损失**

## 5. 最终实验结论

### 5.1 最优创新模型

- `NYUv2`：`bts_nyu_edgeguided_w005`
- `DIODE`：`bts_diode_edgeguided_w002`

### 5.2 消融结论

1. `NYUv2` 上的主要收益先来自边缘监督损失
2. `NYUv2` 上完整模型在 `w=0.05` 时取得最优结果
3. `DIODE` 上单独边缘分支不稳定
4. `DIODE` 上完整模型只有在 `w=0.02` 时超过 baseline
